# ゆらぼ｜制作ポートフォリオ

AIと一緒に制作したWebアプリ・学習成果物をまとめる、PRJ-004の公式Repositoryです。

## 構成

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages（移行確認が完了するまで並行公開）
- GitHub Actions → ConoHa WING（explicit FTPS）
- Microsoft Clarity

作品情報は `js/projects.js` に集約しています。新しい作品はデータ1件を追加することで掲載できます。

正式公開URL: https://yulab-web.com/portfolio/

移行確認用URL: https://yuy080622-source.github.io/yulab-portfolio/

`main` へのpush、またはActions画面からの手動実行で、公開に必要なHTML・CSS・JavaScript・画像だけをConoHa WINGへデプロイします。初期運用ではサーバー側ファイルの削除は行いません。
